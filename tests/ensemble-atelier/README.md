# Ensemble Atelier checks

Build the examples first from repository root:

```bash
python tools/build_ensemble_atelier.py
node --test tests/ensemble-atelier/music.test.cjs
python -m unittest discover -s game-music-composer/scripts/tests -p test_visualize_score.py -v
python -m unittest discover -s game-music-composer/scripts/tests -p test_refine_performance.py -v
```

The Node suite contains 109 tests; the Python extension has 23. They do not replace the canonical release suite.

Optional browser runners require Playwright and an installed Chromium executable. They read `.scratch/ensemble-atelier` by default and write reports and audio in its `qa/results` folder. Screenshots go to `.scratch/screenshots/ensemble-atelier`. Change `GMC_LAB_DIR` for another build and `CHROMIUM_EXECUTABLE` for a different Chromium location. On PowerShell use `$env:GMC_LAB_DIR = '...'` and `$env:CHROMIUM_EXECUTABLE = '...'`, and set `$env:PYTHONUTF8 = '1'` for UTF-8 document and report text. No Python/Node dependency is required by the resulting HTML itself.

```bash
python tests/ensemble-atelier/atelier_tests.py
python tests/ensemble-atelier/index_tests.py
python tests/ensemble-atelier/browser_tests.py
python tests/ensemble-atelier/native_bridge.py
```

Set `GMC_TEST_ID` to I001…I005 to run a single case of the full browser suite. Running separately repeats the registry assertion; counts must not be represented as independent artistic criteria. Browser tests use bundled document content and srcdoc, not a hosted production site or physical mobile devices. The native bridge fixture follows the native JSON shape but is not generated by the original composing engine.

All production approvals, listening comparisons, native sample parity and whole-package checks remain distinct from these tests. Screenshots and WAV outputs are generated evidence, not repository source assets.

## Integrated studio

The original showcase has a separate native bridge test and browser flow:

```bash
node --test tests/ensemble-atelier/studio.test.cjs
python tests/ensemble-atelier/studio_tests.py
```

The four Node cases cover native metadata, circular edits, all generator families, real sample assignments and exact shared-module publication. The 30 browser assertions cover the original piano roll, edits, undo/restore, five generators, real audio from all three banks, Factory WAV, native JSON reopening, pending-play cancellation, focus, the original recipe/review/bank pages, offline requests and desktop/narrow layouts. Browser evidence goes to `.scratch/screenshots/studio-integration`. This runner opens the published page from disk and uses the installed Chrome executable unless `CHROMIUM_EXECUTABLE` selects another location.

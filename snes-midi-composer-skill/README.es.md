# Neo-SPC Composer Skill v3.1

Esta versión integra el **Neo-SPC Factory Bank** en el workflow de composición, render y revisión.

Novedades principales:

- manifest y mapa de roles del banco;
- schema y template de asignación de patches;
- auditor de rango, cobertura y patches inexistentes;
- selección por rol, registro, velocity y perfil de era;
- Neo-16 como perfil live/local;
- Neo-32 como perfil expandido;
- documentación de integración con el showcase v4.1.

# Neo-SPC Composer Skill v3.0

Skill de composición y producción musical retro-expandida inspirada en SNES, con arquitecturas de 12–32 voces, harness generativo completo, interpretación expresiva, mezcla calibrada y una revisión independiente de la partitura como la realizaría un profesor de composición.

## Cambios principales de v3

- 100 composiciones reconstruidas con una nueva semilla y pipeline
- Recipe Builder con 15 módulos de parámetros
- revisión independiente → corrección dirigida → segunda revisión
- 98 composiciones aprobadas y 2 conservadas explícitamente en revisión
- 100 MIDI Type 1 y 100 previews OGG/MP3 validados
